# ترازبان — پیش‌نمایش رابط کاربری مدیر صندوق

این مخزن برای انتشار پیش‌نمایش رابط کاربری واقعی پنل مدیر صندوق ایجاد شده است.

- این نسخه صرفاً پیش‌نمایش رابط کاربری است.
- داده‌ها نمایشی و ساختگی هستند.
- هیچ اتصال به بک‌اند، API یا پایگاه داده وجود ندارد.
- ورود و احراز هویت واقعی فعال نیست.
- هیچ اطلاعات محرمانه یا تنظیمات محیطی از مخزن اصلی در این مخزن قرار نمی‌گیرد.
